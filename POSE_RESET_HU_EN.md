# Csak a póz visszaállítása / Pose-only reset

2026-11-01

Zárd be a régi külön pózlapot, futtasd az UPDATE.cmd fájlt, majd Ctrl+F5 a
Studio főlapján. Nyisd újra a külön pózszerkesztő lapot.

Az alap-póz választó alatt új gomb: Póz visszaállítása — [alkalmazott alap-póz].
Csak a kijelölt figura testtartását állítja vissza az utoljára alkalmazott
alap-pózára (álló, ülő, lépő, felemelt kéz vagy térdelő). A gombon látható a
visszaállított alap neve. Egy még nem alkalmazott legördülő választás ezt nem
módosítja. A figura helye, magassága, elfordítása, neve, megnevezése, színe,
láthatósága és leírása megmarad. A többi figurát, kamerát, fényeket és a
mentett preseteket nem változtatja. Visszavonás / Újraalkalmazás használható.

In English: close old pose tabs, run UPDATE.cmd, Ctrl+F5, reopen the workspace.
Reset pose — [applied base] restores only the selected figure’s last applied
base posture. It retains placement, height, turn, identity, name, colour,
visibility and description. Other figures, camera, lights and saved presets
remain unchanged. A pending unapplied dropdown choice does not change the
reset target. Undo/redo work normally. Eight interface languages.

Known-version checks, verified backups and rollback protect the served page
and NEW registry. No media, archive or user settings are removed. No SwarmUI
restart is required. The separate tab must be reopened to use its new code.
