## English

Run UPDATE.cmd, save open drafts, then Ctrl+F5. No server restart needed.
Find Publication desk near the top, marked NEW. Start from an archive viewer,
Series planner, the current prompt, or the desk's archive search.

Prepare separate EN/HU title, teaser and description fields with individual
copy buttons. Keywords are user-selectable; only checked ones are exported.
The optional AI request opens the existing helper without automatically
submitting. Review the visible brief first. Apply the helper's structured
JSON response with explicit confirmation; malformed responses change nothing.
Applying AI copy clears text review and leaves suggested keywords unchecked.

Prompt/settings sharing is opt-in. Recorded archive metadata snapshots and
planned series values remain distinct. No media inspection is claimed.
The manual checklist covers picture/motion, audio, cover and text review.
Changed series are marked for a fresh review.

The public ZIP contains text and selected passport data, not media files.
Incomplete copy/review produces a DRAFT filename. Private JSON backups include
source data and can be imported as new drafts; keep those backups for yourself.
Up to 25 drafts persist in this browser. Eight-language controls; EN/HU copy.
No automatic upload, transmission or publishing occurs. The updater replaces
only the bundled interface after a verified backup and keeps existing data.
