# Prompt Studio 1.20.0 — Quick start in 8 languages

The new **Director's timeline** is available in all eight interface languages. Plan action, camera and sound in time segments; copy the editable prompt, then enter the displayed FPS and frame count manually in SwarmUI or ComfyUI. Link an archived video and export plans to JSON for backup. The optional **Prompt writing guide** below the mode selector offers typing suggestions, an editable structure, a step-by-step walkthrough, and a local prompt checker. / Az új **Rendezői idővonal** mind a nyolc felületi nyelven elérhető. Tervezd meg időszakaszonként a cselekményt, kamerát és hangot; az FPS-t és képkockaszámot kézzel állítsd be. Archív videót kapcsolhatsz hozzá, a terveket JSON-ba mentheted. A módválasztó alatti **Promptírási szamárvezető** gépelési javaslatot, szerkeszthető vázlatot, lépésenkénti segítséget és helyi promptellenőrt ad.

## English

Extract the ZIP to a writable Windows folder. Double-click `START.cmd`; accept the official Node.js download if prompted. In the browser, add your own media folder in **Searchable media archive**, then click **Refresh archive**. Rate results with 1–5 stars, add categories, and filter. Thumbnails start hidden; enable them for this session or deliberately enlarge an image and open it in the default Windows app. Ollama and `gemma3:4b` are optional for AI features. The clean ZIP contains no personal media or index.

## Magyar

Bontsd ki a ZIP-et írható Windows-mappába. Indítsd a `START.cmd` fájlt; ha kérdezi, engedélyezd a hivatalos Node.js-letöltést. A böngészőben add hozzá a saját médiamappádat a **Kereshető médiaarchívumhoz**, majd kattints az **Archívum frissítése** gombra. A találatokat csillagozhatod, kategorizálhatod és szűrheted. A bélyegképek alapból rejtve vannak; bekapcsolhatod őket erre az alkalomra, vagy egy képet külön nagyíthatsz és megnyithatsz a Windows képnézegetőjében. Az Ollama és a `gemma3:4b` csak az AI-funkciókhoz kell. A tiszta ZIP-ben nincs személyes média vagy index.

Vorschaubilder sind anfangs verborgen; bei Bedarf einblenden oder ein Bild groß und in der Windows-Standard-App öffnen. Ollama und `gemma3:4b` sind nur für KI-Funktionen nötig. Das saubere ZIP enthält keine persönlichen Medien oder Indexdaten.
