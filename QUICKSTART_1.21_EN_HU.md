# Prompt Studio 1.21.0

English: extract the entire ZIP into a new writable folder, then run START.cmd. Node.js 22+ is required; setup can offer a verified portable download. RESTART_STUDIO.cmd restarts only this installation. Close another installation first if it owns port 18819. For existing personal work, follow UPGRADE.md; do not overwrite or delete your old data/browser preferences.

New: Virtual studio → Figures and poses → Open in new tab → Light sphere / Add dog / Add cat. Wheel orbits in 3D with sphere enabled, Shift+wheel tilts, Ctrl+wheel zooms. See LIGHT_SPHERE_PETS_HU_EN.md.

Local AI is optional. Install Ollama and download a vision-capable model separately for image-understanding prompt suggestions; empty model list = setup needed. Use Local AI setup. Finish GPU generation before running local vision. Manual scene tools and archive work without Ollama. Video processing needs a configured FFmpeg; included WAV playback does not need an AI model.

Magyar: az egész ZIP-et csomagold új, írható mappába, majd START.cmd. Node.js 22+ kell; a beállító ellenőrzött hordozható letöltést ajánlhat. RESTART_STUDIO.cmd csak ezt a telepítést indítja újra. Ha másik Studio foglalja az 18819-es portot, előbb azt zárd be. Saját munka költöztetése: UPGRADE.md; a régi adataidat/böngészőbeállításaidat ne töröld.

Újdonság: Virtuális stúdió → Figurák és testtartások → Megnyitás új lapon → Fénygömb / Kutya hozzáadása / Macska hozzáadása. Bekapcsolt gömbnél térbeli nézetben görgő = forgatás, Shift+görgő = billentés, Ctrl+görgő = nagyítás. Útmutató: LIGHT_SPHERE_PETS_HU_EN.md.

A helyi MI opcionális. Képből promptajánláshoz külön Ollama és képértő modell kell; üres modelllista esetén még beállítás szükséges. Használd a Helyi MI beállítása panelt. GPU-generálás közben ne indíts helyi képértést. A kézi jelenettervező és az archívum Ollama nélkül is működik. Videófeldolgozáshoz beállított FFmpeg kell; a kész WAV-ok lejátszásához nem kell MI-modell.
