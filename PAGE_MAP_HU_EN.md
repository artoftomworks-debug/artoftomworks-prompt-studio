# Oldaltérkép és archívum / Page map and archive navigation

2026-11-01

Futtasd az UPDATE.cmd fájlt, majd Ctrl+F5 a Prompt Studióban. A fejléc alatt
kéznél maradó navigációs sáv jelenik meg. Archívum / galéria: odaugrik az
archívumhoz, keresés és dátum módosítása nélkül. Az Oldaltérképből a fő részek,
a műhelyek és a napi galéria is elérhetők. A napi galériát csak akkor kapcsolja
be, ha még nincs nyitva. Csukott rész megnyílik; a Kérdezd az MI-t menüpont csak
az ablakot nyitja meg, nem indít kérést.

A NEW jelölések az Újdonságokkal közösek. Az odaugrás nem jelöli megtekintettnek
a funkciót. Külön elrejthetők és visszakapcsolhatók. Nyolc nyelv, két sötét téma,
kisebb képernyőkhöz igazodó vezérlők és billentyűzetes navigáció.

Négy felületfájlt ellenőriz és mentéssel frissít. Az archívum, média és személyes
beállítások megmaradnak. SwarmUI-újraindítás nem kell. A külön moduláris oldalban
csak a meglévő feature modul és stílusa betöltését adja hozzá.

Run UPDATE.cmd, then Ctrl+F5. A sticky bar below the header provides Archive /
gallery and a Page map. Archive navigation keeps filters/dates. Daily gallery
opens only if not already active. Available main sections and workshops are
listed; closed sections open, and Ask AI opens its dialog without sending.
NEW markers share existing explicit dismissal/restoration preferences; visiting
a section never dismisses them. Eight languages, two dark themes, responsive
controls, keyboard focus and reduced-motion scrolling. Verified backups and
rollback preserve media, archive and settings. No backend restart is needed.

Automated checks cover navigation, filter/day preservation, NEW state sharing,
languages, late-created targets, bundle syntax and installer rollback. Actual
browser layout still needs user acceptance after installation.
