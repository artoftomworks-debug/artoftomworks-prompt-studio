# Megnyitás az Intézőben / Show in File Explorer

1. Futtasd az UPDATE.cmd fájlt.
2. Indítsd újra a Prompt Studiót a megszokott indítóddal, majd Ctrl+F5.
3. Nyiss meg egy képet vagy videót a galériában. A Fájl elérési útjának
   másolása mellett találod a Megnyitás az Intézőben gombot.

A gomb megnyitja a fájl mappáját a Windows Intézőben, és kijelöli a fájlt.
A Megnyitás a gépen gomb továbbra is a hozzárendelt programot indítja.
A frissítő ellenőrzi a verziót, mentést készít; az archívum, képek, videók,
beállítások és mentett munkák megmaradnak. Mind a nyolc nyelv támogatott,
a NEW jelzés külön kikapcsolható. Ha a fájlt áthelyezted, előbb frissítsd az archívumot.

Run UPDATE.cmd, restart Studio with its usual launcher and press Ctrl+F5.
In either gallery viewer, Show in File Explorer sits beside Copy file path.
It opens the original media folder and selects the file. Existing default-app
opening remains available. Windows only. Personal data is preserved.

Validated: 13 automated checks for viewer actions/translations, stale replies,
server origin/action protection, catalog membership and file fingerprint,
shell-free Explorer arguments, existing path copy and NEW labels. Updater
preflight, backups, repeat install and rollback are checked separately.
Actual Windows Explorer selection should be confirmed in the user's UI.
